# Robô Marciano em Kotlin

Projeto desenvolvido para a atividade: Exercícios de Linguagens de programação móvel (22/05/2026 - 28/05/2026)

O objetivo é implementar um robô chamado Marciano, capaz de responder mensagens em uma aplicação CLI, utilizando Kotlin.

## Objetivo da atividade

O projeto deverá implementar:

- uma versão básica do robô;
- uma versão avançada com operações matemáticas;
- uma versão premium com ação personalizada;
- interação via terminal até o usuário digitar `FIM`.

## Linguagem utilizada

- Kotlin

## Tipo de aplicação

- CLI: aplicação executada pelo terminal
